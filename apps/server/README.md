# Z-Meet Server (Backend)

> **NestJS Backend** — Dùng chung cho tất cả nền tảng (Web, Mobile, Desktop).

## Tech Stack (Planned)
- **Framework**: NestJS v11
- **Language**: TypeScript (strict mode)
- **Database**: PostgreSQL + Prisma ORM
- **Real-time**: Socket.IO (WebSocket)
- **Auth**: JWT + Passport.js

## Features (Planned)
- `auth/` — Đăng ký, đăng nhập, refresh token
- `meeting/` — Tạo phòng, tham gia, quản lý session
- `user/` — Quản lý tài khoản người dùng
